# HyperGL Research Log

Structured research docs live in [research.md](research.md). This file is the chronological development journal.

Use this file as the public development journal for the project.

## Entry 01: Project Direction

HyperGL should be both a visual library and a learning tool. The project is now focused on the reusable library, live documentation, effect presets, and shader research instead of a standalone editor.

## Entry 02: Renderer Questions

- How should uniforms be named so beginners understand them?
- Which effects are best as single-pass fragment shaders?
- Which effects need multipass framebuffers?
- How can configs be exported cleanly into React, Next.js, and vanilla JavaScript?
- Which controls are stable enough to become the public customization schema?
